## A Machine Learning Regression Model to Predict the Concentration Quenching of Inorganic Doped-Eu³⁺ Phosphors
# Eu³⁺ Luminescence Quenching Prediction Model

This repository contains a machine learning model developed to predict the **luminescence concentration quenching (LCQ)** of Eu³⁺-doped inorganic materials.

Concentration quenching is an important limiting factor in the performance of luminescent materials. As the activator concentration increases, the emission intensity initially improves but may decrease beyond a critical concentration due to non-radiative energy-transfer processes between neighboring luminescent centers. Identifying this optimal dopant concentration experimentally can require the synthesis and characterization of multiple samples, making the process time-consuming and resource-intensive.

The objective of this project is to investigate whether the quenching concentration of Eu³⁺-activated materials can be estimated from descriptors associated with the host material and its chemical, structural, and physical properties using machine learning.

The model was developed using an experimentally curated dataset of Eu³⁺-doped luminescent materials collected from the scientific literature. Each material is represented by a set of descriptors that may include crystallographic, chemical, electronic, optical, and physicochemical information. Statistical descriptors derived from the elemental composition of the host material are also included.

Several regression algorithms were evaluated during model development, with particular emphasis on **Support Vector Regression (SVR)** and **ν-Support Vector Regression (ν-SVR)**. Feature selection and cross-validation procedures were employed to reduce model complexity and evaluate its generalization performance on the relatively small experimental dataset.

The resulting model is intended primarily as a **screening and decision-support tool**. It can help identify promising Eu³⁺ concentration ranges before experimental synthesis, potentially reducing the number of experimental iterations required during the development of new phosphor materials.

## Main Features

- Prediction of Eu³⁺ luminescence concentration quenching.
- Machine learning models trained on experimentally reported materials.
- Chemical, structural, electronic, and physicochemical descriptors.
- Feature selection to identify the most informative material properties.
- Cross-validation for model assessment.
- Support for screening new Eu³⁺-doped host materials.

## Important Note

The predictions generated by this model should not be interpreted as a replacement for experimental measurements. The model is data-driven and its reliability depends on the chemical and structural similarity between a new material and the materials represented in the training dataset. Predictions for materials outside the training domain should therefore be interpreted with caution.

This project aims to contribute to the application of machine learning in luminescent materials research by providing a computational approach for assisting the design and optimization of Eu³⁺-doped phosphors.
